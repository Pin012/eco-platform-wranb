# 關注議題資料

> 這個檔案控制網站「關注議題」頁面的設施、工程類型、議題及生態保育原則。只要用文字編輯器修改並儲存即可，不需要修改程式碼。

> 修改步驟：先複製一份本檔案備份 → 找到要調整的設施 → 依下方格式修改 → 儲存 → 在專案根目錄執行 `npm run dev` → 開啟終端機顯示的網址並進入「關注議題」確認內容。

## 維護時務必遵守

1. 每個「設施＋工程類型」使用一個 `## 設施名稱｜工程類型` 區塊，中間必須使用全形直線 `｜`；相同設施若有不同工程類型，請分開建立區塊。
2. 設施基本資料固定依序填寫 `設施簡介`、`敏感程度`、`關注團體`、`棲地`、`物種`。欄位名稱、開頭的 `- ` 及全形冒號 `：` 不可更改。
3. `敏感程度` 請填「高」、「中」或「低」。棲地與物種有多項時，必須用中文頓號「、」分隔。
4. 每項議題使用 `### 議題名稱`，下一行填 `- 議題說明：完整說明`；其下必須保留 `#### 生態保育原則`。
5. 每項保育原則各寫一行，以 `- ` 開頭，並以 `[迴避]`、`[縮小]`、`[減輕]` 或 `[補償]` 標示類型，例如 `- [減輕] 施工區定期灑水`。
6. `##`、`###`、`####` 的數量與其後空格不可更改。新增資料時，最安全的方式是複製一個格式完整的既有區塊，再逐欄替換內容。
7. 若要刪除設施或議題，請從其標題開始刪除完整區塊。若頁面顯示異常，先還原備份，再逐項重做修改。

> 正式資料從下方第一個設施標題開始；本段「維護時務必遵守」不會顯示成設施資料。

## 中庄調整池｜河川整治與保育工程

- 設施簡介：中庄調整池位於桃園市大溪區瑞興里與中新里，位於石門水庫與鳶山堰之間的大漢溪河段左岸，供應桃園及新北市板新地區約300萬戶用水。中庄調整池主要功能是作為颱洪期間的備援水源。池區面積約36公頃，總面積則達87公頃，有效蓄水容量約505萬立方公尺
- 敏感程度：低
- 關注團體：里長民意代表群、瑞興社區發展協會、仁愛社區發展協會、月眉社區發展協會、荒野保護協會桃園分會及中華民國野鳥學會
- 棲地：次生林、草生地、農耕地、人工綠地、人工濕地、墓園、水體、裸露地、人工建物
- 物種：臺灣大豆、黑鳶、臺灣藍鵲

### 棲地破壞與喪失

- 議題說明：工程施作或施工便道設置常導致濱溪植被遭移除，造成棲息環境喪失或劣。河道整治恐使水域型態單一化，降低生物多樣性

#### 生態保育原則

- [迴避] 工程施作應迴避自然溪段或是大型喬木等生態敏感區，並以黃色警戒帶標示
- [縮小] 施工便道應沿既有便道路徑設置
- [縮小] 施工便道以可供施工機具單向通行之5公尺寬度為限
- [補償] 營造深潭或淺瀨，避免水域型態單一化

### 水質與環境污染

- 議題說明：施工產生之泥砂、污水與廢棄物導致水質與環境受汙染，影響水陸域生物

#### 生態保育原則

- [減輕] 土砂堆置區應集中且做適當處理
- [減輕] 設立擋排水設施，避免施工污水流入河道

### 物種受工程干擾

- 議題說明：施工期間產生之高噪音與震動會干擾四周物種，且工程若於生物繁殖期或候鳥季進行，將影響族群繁衍

#### 生態保育原則

- [補償] 加強施工廠商生態保育教育宣導

- 議題說明：河道開挖、土方作業及工程材料進入水體可能造成濁度增加、水質惡化及底質改變，影響水域生物與棲地。

#### 生態保育原則

- [減輕]施工盡量以綠色工法或材料為主，減少水泥用量，如就地取材、透水鋪面、乾砌石等
- [減輕]設置排擋水設施或沉砂池，減輕開挖土砂對水體水質影響，利用半半施工法，降低干擾
